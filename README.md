## Mise en pratique

Ces notes m'ont servi à construire
[linux-maintenance-toolkit](https://github.com/Benidoss/linux-maintenance-toolkit) :
des scripts Bash qui surveillent un serveur Linux, sauvegardent un dossier avec rotation
et s'exécutent chaque nuit avec cron.

## Environnement

Ubuntu Server 26.04 LTS dans une VM VirtualBox, à laquelle je me connecte en SSH.
